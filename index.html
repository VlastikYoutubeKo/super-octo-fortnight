Go Production

IPTV Stream Proxy Manager

A production-ready IPTV proxy system acting as a middleman between TVHeadend and upstream Xtream Codes sources. Rewritten in Go for high concurrency and ultra-low latency.

Key Features

  • High Performance: Zero GIL limitations, native Go concurrency.
  • Low Latency: Optimized FFmpeg pipes and raw HTTP proxying.
  • Resiliency: Automatic failover to backup sources and fallback video.
  • Compatibility: Full support for .m3u8 and .ts streams with VLC/TVH.
  • Security: IP and Domain-based whitelisting.

Quick Start

# Build the server
cd src
go build -o ../proxy_server *.go

# Run the server
./proxy_server

API & Proxy Ports

  • Proxy Server: Port 9000
  • REST API / Web UI: Port 9005
