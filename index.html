IPTV Proxy Manager

Go Production

A production-ready, ultra-low latency IPTV proxy system acting as an intelligent middleman between TVHeadend/VLC and upstream Xtream Codes providers. Completely rewritten in Go for extreme concurrency, eliminating Python's GIL limitations, and packed with an AI-driven smart EPG mapping system.

Key Features

  • High Performance: Zero GIL limitations, native Go concurrency.
  • AI-Powered EPG: Uses Gemini AI to map raw channel names to XMLTV EPG IDs automatically.
  • Resilient Failovers: Rotates HTTP proxy requests, falling back to direct connections.
  • M3U Sanitization: Automatically cleans up ugly tags from playlist channel names.
  • Hijacked TCP Pipes: Transmits raw MPEG-TS data directly onto sockets to prevent HTTP corruption.
